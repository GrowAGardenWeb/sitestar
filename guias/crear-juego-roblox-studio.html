Cómo crear tu primer juego en Roblox Studio

Por el equipo de RoGuías · Lectura de 3 min

Cualquier persona con una cuenta de Roblox puede crear juegos gratis usando Roblox Studio. Así puedes empezar.

1. Instala Roblox Studio

Descárgalo desde la página oficial de creadores de Roblox e inicia sesión con tu cuenta.

2. Elige una plantilla

Para tu primer proyecto usa la plantilla Baseplate u Obby. Ya trae lo básico para empezar a construir.

3. Construye

  • Usa Part para agregar bloques y las herramientas Mover, Escalar y Rotar.
  • Activa Anchored en las piezas para que no se caigan.
  • Prueba tu juego con el botón Play todas las veces que quieras.

4. Un script sencillo

Agrega un Script dentro de una pieza para que elimine al jugador que la toque (ideal para un obby):

script.Parent.Touched:Connect(function(hit)
  local hum = hit.Parent:FindFirstChild("Humanoid")
  if hum then hum.Health = 0 end
end)

5. Publica

Ve a Archivo → Publicar en Roblox, ponle nombre y descripción, y compártelo con tus amigos.
